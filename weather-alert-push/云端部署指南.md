# 云端部署指南（不用一直开电脑）

把监测程序放到 **GitHub 免费云端**运行。之后**你自己的电脑开不开都没关系**，云端每 10 分钟自动检查一次并推送预警到你的手机。

- 费用：**0 元**（公开仓库的自动运行时间免费无限）
- 需要：一个 GitHub 账号（免费注册）
- 你的 Bark 密钥会存在 GitHub 的 **Secrets** 里，**不会出现在代码里**，也不会公开

> 适合人群：不想让电脑一直开着。全程在网页上操作，**不用安装任何软件**。

---

## 准备工作（只需一次）

确认你手上有这两样：

1. 项目文件夹（本目录 `weather-alert-push`）
2. 你的 Bark 密钥（就是之前那条 `R2bS39ni4Hz5wuG4EcbjEF`）

---

## 第 1 步：注册 GitHub 账号

1. 打开 <https://github.com/signup>
2. 用邮箱注册（免费），按提示设用户名和密码。

> 已经有账号的话，直接登录跳到第 2 步。

---

## 第 2 步：新建一个仓库

1. 打开 <https://github.com/new>
2. **Repository name** 随便填，例如：`weather-alert`
3. 选择 **Public**（公开）← 一定要选公开，公开仓库的自动运行**免费无限**
4. 勾选 **Add a README file**
5. 点绿色按钮 **Create repository**

> 为什么公开没问题：你的密钥不在代码里，而是放在 Secrets 里，别人看不到。

---

## 第 3 步：上传程序文件

1. 在仓库页面，点 **Add file** → **Upload files**
2. 打开电脑上的 `weather-alert-push` 文件夹，把这些文件**全选拖进去**：

```
main.py            notify.py          source.py
parse.py           matcher.py         store.py
push.py            util.py            config.py
config.example.json
```

3. ⚠️ **不要上传** `config.json`（里面有你的密钥）、`state.db`、`logs` 文件夹。
4. 拉到页面底部，点 **Commit changes**。

---

## 第 4 步：创建自动运行任务

1. 点仓库顶部的 **Actions** 标签。
2. 如果看到提示，点 **I understand my workflows, go ahead and enable them**。
3. 点 **set up a workflow yourself**（自己设置工作流）。
4. 把编辑框里原有的内容**全部删掉**，粘贴下面这一整段：

```yaml
name: 天气预警监测

on:
  schedule:
    - cron: '*/10 * * * *'
  workflow_dispatch:

permissions:
  contents: write

concurrency:
  group: weather-alert
  cancel-in-progress: false

jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - name: 检出代码
        uses: actions/checkout@v4

      - name: 安装 Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.12'

      - name: 恢复推送记录（去重状态）
        uses: actions/cache@v4
        with:
          path: state.db
          key: wa-state-${{ github.run_id }}
          restore-keys: |
            wa-state-

      - name: 生成配置（密钥由 Secrets 注入，不写入代码库）
        run: cp config.example.json config.json

      - name: 运行监测并推送到手机
        env:
          WA_BARK_KEY: ${{ secrets.BARK_KEY }}
          WA_SERVERCHAN_SENDKEY: ${{ secrets.SERVERCHAN_SENDKEY }}
        run: python main.py

      - name: 心跳保活
        run: |
          if [ ! -f heartbeat.txt ] || [ -n "$(find heartbeat.txt -mtime +6 2>/dev/null)" ]; then
            date -u +"%Y-%m-%dT%H:%M:%SZ" > heartbeat.txt
            git config user.name "github-actions[bot]"
            git config user.email "41898282+github-actions[bot]@users.noreply.github.com"
            git add heartbeat.txt
            git commit -m "chore: keep-alive heartbeat" || true
            git push || true
          fi
```

5. 看左侧文件名框，改成：`weather-alert.yml`
6. 点右上角 **Commit changes**，再点一次 **Commit changes** 确认。

---

## 第 5 步：填入你的 Bark 密钥

1. 在仓库页面点 **Settings**（设置）。
2. 左侧菜单找到 **Secrets and variables** → 点 **Actions**。
3. 点绿色按钮 **New repository secret**。
4. **Name** 填：`BARK_KEY`
5. **Secret** 填你的 Bark 密钥（例如 `R2bS39ni4Hz5wuG4EcbjEF`）
6. 点 **Add secret**。

---

## 第 6 步：手动跑一次，确认成功

1. 回到仓库的 **Actions** 标签。
2. 左侧点 **天气预警监测**。
3. 右侧点 **Run workflow** → 再点绿色的 **Run workflow**。
4. 等约 1 分钟，刷新页面：
   - 出现**绿色对勾 ✅** = 成功
   - 出现**红色叉 ❌** = 失败（把报错发给我，我帮你看）

跑成功后，**你手机上应该收到预警**（如果当前有符合条件的预警）。

---

## 之后就不用管了

- 云端会**每 10 分钟自动运行一次**，电脑关机、断网都不影响。
- 同一条预警不会重复推送；预警升级或解除会再推一次。
- 工作流里已经内置了"心跳保活"，不会被 GitHub 自动停用。

## 常见问题

**Q：怎么改关注的城市或预警级别？**
在仓库里点开 `config.example.json` → 点右上角铅笔图标编辑 → 改完点 **Commit changes**。

**Q：怎么确认它还在正常运行？**
仓库 **Actions** 标签里，能看到每 10 分钟新增一条运行记录。

**Q：会不会花很多钱？**
不会。公开仓库的 Actions 运行时间**完全免费**，本项目每次只跑十几秒。

**Q：万一将来被停用了怎么办？**
GitHub 会在停用前给你发邮件，点邮件里的按钮重新启用即可。内置的心跳步骤已经尽量避免了这种情况。

**Q：我想同时推送到微信？**
在第 5 步再加一个 Secret：Name 填 `SERVERCHAN_SENDKEY`，Value 填你的 Server酱 SendKey 即可（代码会自动识别并启用）。
